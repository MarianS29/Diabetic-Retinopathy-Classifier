New/Diabetic_Balanced_Aug
-------------------------
- organize_diabetic_balanced_aug_resized.py
  - Organizeaza `resized_train` si `resized_train_cropped` pe clase `0..4`.
  - Output: `Diabetic_Balanced_Aug_resized_train*`.

- clean_balanced_aug_resized_train.py
  - Curata imaginile slabe: blur, luminozitate, contur, zoom.
  - Output: `cleaned_dataset/0..4`.

- split_the_cleaned_dataset.py

- ben_graham+augment_the_split_dataset.py

  - Output: `processed_by_me/balanced_aug_new/final_balanced_augmented+ben_graham_dataset`.

Procesari + augmentari:
----------------------------------------------------------------------
-> Redimensionare la 512 x 512.
-> Conversie în grayscale.
-> Threshold pe pixeli:
  -> cv2.threshold(gray, 10, 255, cv2.THRESH_BINARY)
-> Curățare mască cu morfologie:
  -> cv2.morphologyEx(..., cv2.MORPH_OPEN, kernel 15x15 eliptic)
-> Detectare contur ochi, se ia cel mai mare contur.
-> Se creează mască pentru ochi.
-> Masca este erodată cu kernel eliptic 11 x 11.
-> Ben Graham pe grayscale:
  -> blur = cv2.GaussianBlur(gray, (0, 0), sigma_x=size/30)
  -> ben_graham_gray = cv2.addWeighted(gray, 4, blur, -4, 128)
-> Exteriorul ochiului devine gri (128), iar în jur se creează un halo folosind distanceTransform.
-> I--------------------nteriorul măștii primește imaginea Ben Graham procesată.
